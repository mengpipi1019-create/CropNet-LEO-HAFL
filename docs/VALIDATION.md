# 共享版本验证

日期：2026-10-08。原始已完成实验不被改写；共享版本位于独立目录。

- 19 项短测试通过：三方法 × 三种子的真实训练控制流程（小型合成网络）、九组最终评估、暂停恢复精确性、曲线提交边界、下载重试、损坏输入拒绝、监督进程重启上限、新目录准备和重复准备。
- 固定下载清单核验：282 个文件，57.0257 GiB；2021 年 222 县、2022 年 254 县；三个种子和 120 轮配置保持不变。
- 从 2,286 条历史评估预测重新计算 RMSE、Corr²、Corr、标准 R²，与已保存指标差异低于 1e-9。
- 2,169 个训练探针点通过内容哈希与逐点指标重算；末尾均达到 120 个已接收样本轮次等价预算。
- 最终对比图、散点图、三线表与全部轮次训练曲线重新生成成功。
- 真实 MMST 网络（41,628,412 参数）在 CUDA 上完成合成输入前向、反向与参数更新；seed 10 初始化哈希与原实验相同。报告见 `evidence/model_interface_check.json`。

本次发布验证不重新训练完整农业模型，也不重新下载 57 GiB 数据。短测试中的模型为合成小网络，不能替代农业性能实验。数据准备的新入口做了固定清单、控制流程与恢复测试，尚未在另一台空白机器完整下载和长跑。

`evidence/original_source_sha256.json` 为原实验源码清单。共享版本的路径、入口、文档与来源清单见 `evidence/publication_manifest.json`；此版本不是原实验文件树的逐字节克隆。模型、核心训练引擎与聚合数值逻辑保持原样。

结果 JSON 仅清理一个分析元数据中的本机绝对目录，并保留原哈希在 `evidence/metadata_redactions.json`。逐县预测及训练探针数值没有更改。权重哈希供追溯，但权重本体不在 Git 仓库中，因此读者仅凭共享包不能再次验证模型文件哈希或执行其推理。
